# Iris Luo — Portfolio

A responsive portfolio for a Graduate Product Designer / UI/UX Designer with a front-end background. Built with HTML, CSS and JavaScript.

## Local development

```sh
npm install
npm run dev
```

Open http://127.0.0.1:8081. Run `npm run build` to create the static production site in `dist/`.

See [CONTENT_GUIDE.md](CONTENT_GUIDE.md) for editing text, project images, videos and the CV.
